## Getting Started
1. **Prerequisites:**  
   - Ensure you have access to the Pinterest business account.
   - Install required dependencies.

2. **Clone the Repository:**  
   ```bash
   git clone https://github.com/stovey8215-oss/pinterest-skincare-pin-agent.git
   cd pinterest-skincare-pin-agent
   ```

3. **Configure the Application:**  
   - Update the configuration file with your Pinterest API credentials.

---

## Creating a Campaign
1. **Navigate to Campaign Section:**  
   - Go to the campaigns tab in the application.

2. **Fill in Campaign Details:**  
   - Enter the campaign name.
   - Specify the target audience and duration.

3. **Upload Pins:**  
   - Select images and descriptions for your pins.
   - Ensure all images meet Pinterest’s guidelines.

4. **Launch Campaign:**  
   - Click the ‘Launch’ button to start the campaign.

---

## Managing Your Campaigns
- **Edit Campaigns:**  
  - You can edit ongoing campaigns by selecting the campaign and clicking ‘Edit’.

- **Pause/Resume Campaigns:**  
  - To pause a campaign, select it and click ‘Pause’. To resume, click ‘Resume’.

---

## Analyzing Campaign Performance
- **Access Analytics Dashboard:**  
  - Go to the analytics section to view performance metrics.

- **Key Metrics to Monitor:**  
  - Impressions, Clicks, Engagement Rate, Conversion Rate.
